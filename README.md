# 🚗 Car Parking Management System

## 📌 Overview
This project was developed during my **3rd semester** as part of learning Data Structures.  
It demonstrates how core concepts can be applied to build a real-world parking management system.

---

## 🎯 Features
- Smart Parking Slot Allocation
- Waiting Queue Management (FIFO)
- Auto-Parking from Queue
- Vehicle Search System
- Parking History Tracking
- Data Persistence using Local Storage
- Interactive UI

---

## 🧠 Data Structures Used
- **Array** → Parking slot management  
- **Queue** → Handling waiting vehicles  
- **Stack (concept)** → Operation history tracking  
- **Searching logic (BST concept)**  
- **Dynamic storage handling**

---

## 💻 Technologies Used
- HTML  
- CSS  
- JavaScript  

---

## 🚀 How to Run
1. Download or clone the repository  
2. Open the project folder  
3. Run `Parking_system.html` in your browser
