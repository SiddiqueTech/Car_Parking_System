# 🚗 Car Parking System (DSA Project)

## 📌 Description
This project is a Car Parking System implemented using Data Structures. It manages vehicle entry, exit, and parking slots efficiently.

## ⚙️ Features
- Add vehicle (Entry)
- Remove vehicle (Exit)
- Display parking status
- Slot management

## 🧠 Data Structures Used
- Stack
- Queue
- Arrays

## 💻 Language
-  C++ or html

## 🚀 How to Run
1. Open project
2. Run Parking_system.html file
3. Follow menu options
